# My Schedule PWA

개인용 일정관리 PWA 초기 버전입니다. 서버 계정 없이 브라우저 로컬 저장소에 일정을 저장합니다.

## 포함 기능
- 월간 달력 및 날짜별 일정 목록
- 일정 추가 / 수정 / 삭제
- 카테고리 색상
- 완료 체크
- 메모
- 매일 / 매주 / 매월 / 매년 반복
- JSON 백업 및 복원
- 오늘 일정 요약 패널(앱 내부 위젯)
- 앱이 열려 있을 때 브라우저 알림 확인

## iPhone에서 실행하는 방법
PWA 설치에는 HTTPS 주소가 필요합니다. 파일을 직접 열거나 `file://`로 실행하면 홈 화면 설치 및 서비스 워커가 정상 동작하지 않습니다.

1. 프로젝트 파일을 HTTPS를 지원하는 정적 호스팅에 올립니다. 예: GitHub Pages 또는 개인 웹호스팅.
2. iPhone Safari에서 배포된 HTTPS 주소를 엽니다.
3. 공유 버튼 → '홈 화면에 추가'를 선택합니다.
4. 홈 화면 아이콘으로 실행합니다.

## 로컬 미리보기
프로젝트 폴더에서 간단한 정적 서버를 실행하세요.
Python이 설치된 PC라면:
`python -m http.server 8000`
그 다음 같은 네트워크의 iPhone Safari에서 PC의 로컬 IP와 `:8000` 주소로 접속할 수 있지만, iOS 설치 및 알림 테스트는 HTTPS 배포 환경을 권장합니다.

## 현재 버전의 제한
- iOS PWA의 백그라운드 알림은 이 프로젝트만으로 보장되지 않습니다. 안정적인 푸시 알림은 Push API, 서버, VAPID 키 및 HTTPS 구성이 추가로 필요합니다.
- iPhone 홈 화면의 시스템 위젯은 PWA가 직접 만들 수 없습니다. 현재는 앱 내부 오늘 일정 요약 패널입니다.
- 반복 일정의 완료 상태는 원본 반복 일정에 연결됩니다.
- 데이터는 해당 브라우저의 로컬 저장소에만 있습니다. 정기적으로 JSON 백업을 권장합니다.

## 다음 개발 권장 순서
